# Lithocoon

Application de **lithothérapie** de bien-être (marque Bengacoon).

Ce dépôt public héberge le **manifeste de mise à jour** (`latest.json`) interrogé par l'application, et les **binaires** publiés dans les *Releases*. Le code source n'est pas public.

- Version gratuite (découverte) et version complète.
- 100 % hors ligne : aucune donnée personnelle collectée.

*La lithothérapie est présentée comme une tradition de bien-être ; l'application ne fournit aucun conseil médical.*
